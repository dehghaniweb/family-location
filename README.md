# موقعیت خانواده — راهنمای کامل

وب‌اپی ساده و زیبا برای سه نفر (علی / سارا / امیرآرشا): هرکس با پروفایل خودش وارد می‌شود،
موقعیتش به‌صورت زنده روی نقشه برای بقیه نمایش داده می‌شود، و اگر Cloudflare در ایران فیلتر شود،
اتصال به‌طور خودکار از مسیر Google Apps Script رد می‌شود.

## اجزای پروژه
| فایل | کجا می‌رود |
|---|---|
| `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-180.png` | GitHub Pages |
| `worker.js` | Cloudflare Workers |
| `apps-script/Code.gs` | Google Apps Script |

سه بخش کاملاً جدا از هم هستند؛ فقط چند آدرس/کلید بین‌شان رد و بدل می‌شود.

---

## گام ۱ — Cloudflare Worker (ذخیره موقعیت‌ها)
1. در [dash.cloudflare.com](https://dash.cloudflare.com) یک Worker جدید بسازید و کد `worker.js` را در آن جای‌گذاری کنید.
2. یک **KV Namespace** بسازید و در تنظیمات Worker با نام **`LOCATIONS`** به آن bind کنید.
3. یک **Secret** به نام **`FAMILY_TOKEN`** بسازید — یک رشتهٔ تصادفی و بلند انتخاب کنید (مثلاً از یک رمزساز آنلاین).
4. Deploy کنید و آدرس نهایی را یادداشت کنید (چیزی شبیه `https://family-location.xxxx.workers.dev`).

## گام ۲ — Google Apps Script (پل اتصال + رمزهای عبور)
1. به [script.google.com](https://script.google.com) بروید → پروژه جدید → کد `apps-script/Code.gs` را کامل در آن جای‌گذاری کنید.
2. داخل تابع `printPasswordHashes` سه رمز دلخواه (برای علی، سارا، امیرآرشا) را به‌جای متن نمونه بنویسید.
3. از بالا تابع `printPasswordHashes` را اجرا کنید (Run) — اولین بار مجوز اجرا می‌خواهد، تأیید کنید.
4. از منوی **View → Logs** سه رشتهٔ هش‌شده را کپی کنید.
5. از آیکون چرخ‌دنده (**Project Settings**) → **Script Properties** → **Add script property** و این ۵ مورد را بسازید:

   | کلید | مقدار |
   |---|---|
   | `PASS_ali` | هش رمز علی (از مرحله ۴) |
   | `PASS_sara` | هش رمز سارا |
   | `PASS_amirarsha` | هش رمز امیرآرشا |
   | `FAMILY_TOKEN` | دقیقاً همان مقدار Secret که در گام ۱ ساختید |
   | `CF_WORKER_URL` | آدرس Worker از گام ۱ (بدون `/` در انتها) |

6. **Deploy → New deployment → نوع: Web app**. Execute as: **Me**، Who has access: **Anyone**. Deploy کنید و آدرس را کپی کنید (به `/exec` ختم می‌شود).

> رمزهای واقعی هیچ‌وقت داخل `index.html` یا هیچ فایل دیگری نوشته نمی‌شوند؛ فقط همین‌جا، به‌صورت هش‌شده.

## گام ۳ — یک تنظیم در index.html قبل از انتشار
فایل `index.html` را باز کنید، نزدیک ابتدای تگ `<script>` دو خط زیر را پیدا کنید و با مقادیر خودتان جایگزین کنید:
```js
const CF_WORKER_URL   = 'YOUR_CLOUDFLARE_WORKER_URL';   // آدرس گام ۱
const APPS_SCRIPT_URL = 'YOUR_APPS_SCRIPT_WEBAPP_URL';  // آدرس گام ۲ (همان .../exec)
```

## گام ۴ — انتشار روی GitHub Pages
1. یک repository جدید بسازید (Public، چون GitHub Pages رایگان روی ریپوی خصوصی فقط با پلن پولی کار می‌کند).
2. فایل‌های `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-180.png` را در ریشهٔ ریپو آپلود کنید (پوشهٔ `apps-script` و `worker.js` را هم می‌توانید همان‌جا نگه دارید، فقط برای مرجع — تأثیری در صفحه ندارند).
3. **Settings → Pages → Source: Deploy from a branch → main / (root) → Save.**
4. چند دقیقه صبر کنید؛ آدرس نهایی چیزی شبیه `https://USERNAME.github.io/REPO/` خواهد بود.

## گام ۵ — ورود هرکدام از شما، روی گوشی خودش
1. آدرس GitHub Pages را در Chrome باز کنید.
2. آواتار خودتان (علی / سارا / امیرآرشا) را بزنید و همان رمزی که برایش هش ساختید را وارد کنید.
3. وقتی گوشی اجازهٔ موقعیت مکانی را پرسید، تأیید کنید.
4. از منوی ⋮ کروم، گزینهٔ **«افزودن به صفحه اصلی» (Add to Home screen)** را بزنید — از این به بعد مثل یک اپ مستقل با آیکون خودش روی گوشی است.

مرورگر این ورود و این مجوز را خودش برای دفعات بعد به خاطر می‌سپارد — نیازی به وارد کردن دوبارهٔ رمز یا دادن دوبارهٔ مجوز نیست.

## گام ۶ — تبدیل به «اپ مورد اعتماد» در اندروید (یک‌بار، روی هر گوشی)
بعد از افزودن به صفحهٔ اصلی:
- **Settings → Apps → موقعیت خانواده → Permissions → Location → Allow all the time (همیشه مجاز)**
- **Settings → Apps → موقعیت خانواده → Battery → Unrestricted (بدون محدودیت باتری)**
- در گوشی‌های شیائومی/هواوی و مشابه، گزینهٔ **Autostart / اجرای خودکار** را هم برای آن روشن کنید.

این دقیقاً همان کاری‌ست که اپ‌هایی مثل Life360 یا Find My Device از شما می‌خواهند، و اپ را از نظر اندروید «مورد اعتماد و همیشه فعال» می‌کند.

## گام ۷ (اختیاری) — ساخت یک APK واقعی، بدون کدنویسی
اگر دوست دارید یک آیکون اپ واقعی (نه فقط میانبر مرورگر) روی گوشی داشته باشید:
1. وارد [pwabuilder.com](https://www.pwabuilder.com) شوید و آدرس GitHub Pages‌تان را بدهید.
2. گزینهٔ **Android package** را بسازید و دانلود کنید.
3. APK را روی هر گوشی نصب کنید (چون از گوگل‌پلی نیست، باید اجازهٔ «نصب از منابع ناشناس» را یک‌بار بدهید).

این روش یک اپ اندرویدی واقعی با آیکون و دیالوگ‌های مجوز مثل هر اپ دیگر می‌سازد.

---

## نکتهٔ صادقانه دربارهٔ «همیشه در دسترس بودن» 🔴
با تنظیمات بالا (PWA نصب‌شده + مجوز Location روی «همیشه» + بدون محدودیت باتری)، ارسال موقعیت در پس‌زمینه معمولاً خیلی خوب و پایدار کار می‌کند. اما یک تضمین صددرصد — حتی وقتی گوشی ری‌استارت شده یا اپ به‌زور بسته شده — فقط با یک اپ بومی اندروید با Foreground Service ممکن است؛ همان چیزی که در نسخهٔ اول این پروژه هم به‌عنوان «نسخهٔ بعدی» پیش‌بینی شده بود. اگر در آینده خواستید، می‌توانیم آن را هم به‌عنوان قدم بعدی بسازیم.

## تغییر رمز عبور در آینده
کافی‌ست دوباره در Apps Script تابع `printPasswordHashes` را با رمز جدید اجرا کنید، هش تازه را از Logs بردارید، و مقدار `PASS_xxx` مربوطه را در Script Properties جایگزین کنید. نیازی به تغییر `index.html` یا Worker نیست.

## حریم خصوصی
هر نفر فقط با وارد کردن پروفایل و رمز خودش وارد می‌شود؛ موقعیت هرکس فقط وقتی ارسال می‌شود که خودش وارد شده و مجوز را داده باشد، و هرکس هر وقت بخواهد با خروج از حساب یا لغو مجوز Location، اشتراک‌گذاری را متوقف می‌کند.
